# Medi Reminder AI 💊

## Your Personal Voice Medicine Assistant

Medi Reminder AI is an accessible healthcare platform designed to make medicine management easier through smart reminders, voice assistance, prescription scanning, medicine history, family support, symptom check-ins, and emergency assistance.

## Key Features

- 🎙️ Voice Assistant
- ⏰ Smart Medicine Reminders
- 💊 Medicine Management
- 📷 Prescription Scanning
- 📋 Medicine History
- 👨‍👩‍👧 Family & Caregiver Support
- 🚨 Emergency Assistance
- 🌐 English & Urdu Support
- 📱 Simple and Accessible Interface

## Technology

- HTML
- CSS
- JavaScript
- Web Speech API
- Browser-based storage and features

## Project Purpose

The goal of Medi Reminder AI is to make medicine management simpler, more accessible, and easier to use, especially for users who may benefit from voice-based assistance.
